## URL Parameters

Explorer filter state is stored in the URL query string so views are shareable and reload-safe. All parameters are optional; omitted keys use their default.

| Key | Applies to | Default | Meaning |
| --- | ---------- | ------- | ------- |
| `entity` | all | `jobs` | Active tab: `jobs`, `boards`, or `providers`. |
| `q` | all | *(empty)* | Free-text query across the active entity's searchable fields. |
| `source` | jobs, boards | *(empty)* | Filter by source catalog key (`sourceKey`). |
| `provider` | jobs, providers | *(empty)* | Filter by provider adapter id (`providerId`). |
| `jobStatus` | jobs | `open` | Job lifecycle filter: `open` or `closed`. |
| `support` | providers | *(empty)* | Provider support level: `detect`, `jobs`, or `unsupported`. |
| `routeStatus` | jobs | *(empty)* | Route health filter, for example `route_ready`. |
| `workplace` | jobs | *(empty)* | Substring match on workplace type. |
| `employment` | jobs | *(empty)* | Substring match on employment type. |
| `location` | jobs | *(empty)* | Substring match on job locations. |
| `sort` | all | entity-specific | Sort key; valid values depend on `entity` (for example `latest`, `relevance`, `title` for jobs; `name`, `source` for boards; `provider`, `support`, `status` for providers). |
| `page` | all | `1` | 1-based page number over the currently visible rows. |

Copy the address bar URL to share an exact explorer view, including entity, filters, sort, and page.

Refresh the snapshot after regenerating `kaggle/openoppsdb.sqlite`:

```bash
cd docs && pnpm data:generate:search
```
