# Contributing

OpenOpps contribution workflow, local setup, validation commands, and review expectations live in the docs site.

- **Docs route:** `/docs/contributing` when running the docs app
- **Source:** [`docs/content/docs/contributing.mdx`](docs/content/docs/contributing.mdx)

From the repository root:

```bash
cd docs && pnpm install && pnpm dev
```

Then open `/docs/contributing`. For validation before a PR, see that guide and run `just quick` or `just ci` from the repo root.
